Pharos

A peer-to-peer preprint archive. No single library to burn.

Named after the Lighthouse of Alexandria, which stood for 1,500 years guiding scholars to the world's greatest library. Pharos is a network of beacons, each guiding researchers to preserved preprints, with no single library to burn.

Hypercore BLAKE2b ORCID MIT License

The Problem

Centralized preprint servers are fragile. They run deficits, sit behind Cloudflare, and can be purged overnight. A decentralized archive eliminates single points of failure and single points of control.

Architecture

Five layers, each independently replaceable, composed into a single P2P system.

1

Ingestion

Author-direct publishing via CLI or web UI upload. No external ingestion in MVP.

2

Storage

Hyperdrive v13 with Corestore. Content-addressed by BLAKE2b-256 hash.

3

Index

Hyperbee for structured metadata. SQLite FTS5 for full-text search via Node built-in node:sqlite.

4

Replication

Hyperswarm topic-based peer discovery. Separate topics for metadata and blob transfer. Category-based auto-pinning.

5

Verification

BLAKE2b content hashing + Ed25519 signatures. Paper IDs encode subject, date, and sequence.

Paper ID Format

Example pharos:q-bio.GN/2026.08.28/001

prefix · subject · date · sequence (3-digit, zero-padded)

Features

PublishUpload PDFs via CLI or web UI. ORCID-verified identity.
SearchFull-text search across all papers with SQLite FTS5.
VersioningRevisions linked via previous_version_hash.
DedupContent-addressed storage eliminates duplicates automatically.
P2P ReplicationJoin Hyperswarm, serve and fetch blobs from peers.
Health TrackingAt-risk paper detection with pin count monitoring.
Web UIBrowse, search, read PDFs, upload, view version history.
Storage MgmtDisk usage reporting and eviction of unpinned papers.

Get Started

Install

git clone https://github.com/tpaixao/pharos.git
cd pharos
npm install

Publish a paper

node src/index.js publish paper.pdf \
  --title "A Novel Approach to Single-Cell Analysis" \
  --subject q-bio.GN \
  --author "Tiago Paixao" \
  --abstract "We propose..."

Search

node src/index.js search "single cell bayesian"

Start the P2P daemon

node src/index.js serve

Launch web UI

node src/index.js web  # default port 8093
